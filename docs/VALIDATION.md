# 设备验收

本文是可重复执行的验收清单，不预设某个版本已经通过。自动检查与构建入口见[开发与验证](DEVELOPMENT.md)和[构建与发布](../BUILD.md)，协议和资源归属见[项目结构与执行流程](ARCHITECTURE.md)。

## 验收准备

- 使用需要验收的提交和构建号，记录源码是否含未提交改动；完成受影响平台的自动检查与构建。
- 安装对应 Android APK 或有效签名的 iOS 应用，记录设备型号与系统版本。
- 准备 NKAS API v2 后端，以及启用 ADB 的 Android 真机、模拟器或 redroid。核对后端实例与原生控制目标。
- 直连场景确认 ADB 端口可达并允许客户端身份；Tailscale 场景准备节点身份、ACL 和需要的子网路由。
- 完成应用的 STAR 验证。需要测试安全入口时，准备有权操作的后端及备用客户端。
- 输入测试使用可观察的测试界面；任务启动、配置更改和凭据轮换仅在获准的测试环境执行。

## 后端与设置

| 场景 | 操作 | 预期 |
| --- | --- | --- |
| 后端连接 | 保存有效地址、无效地址、不可达地址和不兼容 API 地址 | 成功后进入已连接状态；失败保留输入并显示原因；API 不兼容有明确提示 |
| 草稿与返回 | 编辑后端地址或控制配置，分别保存与返回 | 保存后使用新值，未提交的编辑不生效 |
| 实例与任务 | 切换实例，检查配置、队列、状态和日志；在测试实例启停任务 | 数据对应所选实例，结果来自后端；控制地址不随实例改写 |
| 表单与调度 | 编辑数字、多行、多选、顺序和调度字段，模拟保存失败 | 合法值正确提交，无效值被阻止，失败保留草稿并可重试 |
| 日志浏览 | 打开长日志、上翻、回到底部、刷新与筛选 | 默认显示最新内容；手动阅读不被新日志强制打断 |
| 可访问性 | 浅深色、小屏、放大字体和键盘展开 | 无布局溢出，主要操作和输入可访问 |

## 安全入口

| 场景 | 操作 | 预期 |
| --- | --- | --- |
| 开启保护 | 在部署页开启入口，使用完整链接连接并重启应用 | API、图片、日志/状态/队列 WebSocket 正常，凭据可恢复，界面只显示根地址 |
| 错误入口 | 填写错误或过期入口 | 明确显示授权错误，不因状态接口返回 HTTP 200 而误报已连接 |
| 轮换 | 从一个客户端重新生成入口 | 旧入口和连接失效；执行轮换的客户端保存新凭据，其他远程客户端提示重新填写 |
| Android 本机恢复 | 在本机 Termux 模式开启或轮换入口 | 应用可重读本机凭据并恢复；任务不因入口操作被停止 |
| 手动回环地址 | 手动填写与本机相同的回环地址 | 按远程连接处理，不自动读取或复用本机凭据 |
| 关闭与重启用 | 关闭保护、用普通地址连接，再开启 | 普通连接恢复；后端保留的入口可再次使用；部署还原默认不清除入口设置 |
| 凭据隔离 | 检查普通设置、日志、备份规则和跨地址请求 | 入口密钥不进入普通日志或备份，不附加到其他后端请求 |

## 原生控制与网络

| 场景 | 操作 | 预期 |
| --- | --- | --- |
| 直连地址 | 使用 `host:port`、`adb://host:port` 与 IPv6 地址 | 地址正确解析，授权后连接到指定 Android |
| Tailscale 注册 | 输入 AuthKey 验证，再重启应用留空连接 | 首次注册成功，之后复用节点身份，AuthKey 不出现在日志中 |
| MagicDNS / 子网 | 分别连接 Tailscale IP、MagicDNS 和获准子网内地址 | 在路由及 ACL 允许时可连接；应用内转发仅监听 `127.0.0.1` |
| 取消与清除身份 | 注册等待中取消，活动连接中清除身份 | 操作可结束，转发关闭，清除后需重新注册 |
| 首帧 | 从截图预览启动控制 | 首帧前保持截图，首帧可用后显示实时 Texture |
| 输入 | 点击四角、长按、滑动、取消手势、返回和主页 | 坐标正确，长按持续，取消释放，无旧指针残留 |
| 文本 | 输入 ASCII、少量多字节字符和超长文本 | 按支持范围注入，超过 300 UTF-8 字节不发送 |
| 旋转与编码 | 旋转目标，按需在调试配置使用 H.264 / H.265 | 尺寸与解码器正确更新，支持该编码的设备可出图 |
| 截图回退 | 断开控制或中断目标网络 | 旧 Texture 清除，恢复两秒截图请求；后端不可达时显示错误或空态 |
| 网络切换 | 在 Wi-Fi 与蜂窝网络间切换 | 旧会话释放，前台按条件重连；连续失败最多自动重试三次 |
| Android 后台 | 控制时切换应用，再返回 | 活动前台服务维持连接；后台断线后回前台恢复；停止后服务结束 |
| iOS 后台 | 进入后台再回前台 | 后台视频和转发停止，回前台重新连接仍被请求的会话 |
| 快速切换 | 多次连接、断开、打开设置和切换实例 | 旧事件不覆盖新会话；主动停止后不自动重连 |
| 本机部署 | 完成 Termux 初始化、无线配对，选择本机虚拟屏幕 | 本机服务可访问；虚拟屏幕使用回环 ADB 与独立身份，不经过 tsnet |
| 初始化异常 | 模拟命令回调延迟、已有安装进程、脚本失败和重试 | 回调超时不误报脚本退出；接续已有进程；真实错误出现在对应步骤 |

文本注入和虚拟屏幕受目标 Android 系统及应用能力限制。H.265 的协议支持不能替代具体设备的解码测试。

## 原生 API 诊断

可在调试代码中通过 `NkasPlatform` 检查最小链路：

1. `tsnetConfigure(key)` → `tsnetConnect()`，或复用已保存的节点身份。
2. `nativeAdbConnect(endpoint, useTailscale: true)`，由原生会话创建和管理转发；直连时关闭该选项。
3. `nativeAdbShell('getprop ro.product.model')` 核对设备型号。在获准的测试目标上，可向 `/data/local/tmp/nkas-probe.txt` 执行 push/pull 核对字节，再删除该测试文件。
4. `nativeAdbClose()` 后检查转发数和会话资源已清理；重复停止不应报错。

需单独观察转发时，调用 `tsnetStartForward(endpoint, localPort: 0)`，再用原生 ADB 连接其返回的 `127.0.0.1:<port>`。停止承载当前控制的转发应结束控制并取消自动重连。iOS 的进程级 ADB smart-socket server 与设备会话分开管理，不要求每次停止控制都终止进程级 server。

## 记录结果

验收记录随对应问题或版本保存，至少包含：

- 提交、是否 dirty、应用显示版本与构建号，以及工作流运行链接。
- 手机系统/型号、后端版本、目标 Android 或 redroid 版本、直连或 Tailscale 网络方式。
- 实际执行的场景、通过/失败/未执行结果、复现步骤和已脱敏日志。
- 未覆盖的设备能力或环境条件。

编译成功、模拟器测试与真机链路验收分别记录，不能互相替代。对外分发另需核对[许可证与分发要求](DEVELOPMENT.md#许可证与分发核查)，包括 iOS ADB 移植胶水的授权与 GPLv3 链接兼容性。
